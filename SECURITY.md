# Security Policy

## Reportar vulnerabilidades

Se você encontrar uma vulnerabilidade de segurança, por favor **não** abra uma issue pública.
Entre em contato diretamente:

- GitHub: https://github.com/brianlewislife-png
- Telegram: https://t.me/brianlewisdev

Inclua detalhes e passos para reproduzir. Responderemos em até 7 dias.

## Escopo

Este projeto é um driver de kernel. Vulnerabilidades relevantes incluem
execução de código no kernel, escalonamento de privilégios e exposição de dados.
