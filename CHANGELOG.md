# Changelog

## [1.0.0] - 2026-11-23

### Adicionado
- Driver AIC8800D80 para adaptador USB WiFi 6 Dual Band (2 antenas).
- Regras udev para modeswitch automático (pendrive -> WiFi) para `a69c:5721` e variantes.
- Instalador universal (DKMS) com detecção de distribuição.
- Atalho `instalar_debian.sh` para Debian/Ubuntu (um clique).
- Scripts `diagnostico.sh` e `eject_placa.sh`.
- Firmware aic8800D80.
- Configuração `usb_modeswitch` para clones Pandora.
- Documentação em português (`README_PT.md`) e inglês (`README.md`).
- Créditos obrigatórios de Brian Lewis (`CREDITS.md`).

### Base
- Fork do projeto RicknotDev/aic8800d80 (MIT), adaptado e empacotado.
