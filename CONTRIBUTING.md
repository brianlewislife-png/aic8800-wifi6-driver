# Contributing

Obrigado por contribuir! Este projeto segue as diretrizes abaixo.

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch: `git checkout -b minha-mudanca`
3. Faça suas alterações e commit: `git commit -m "descricao clara"`
4. Push: `git push origin minha-mudanca`
5. Abra um Pull Request.

## Regras

- Mantenha os **créditos de Brian Lewis** intactos (veja `CREDITS.md`).
- Não remova cabeçalhos de créditos dos scripts.
- Teste em pelo menos uma distribuição antes de enviar PR.
- Descreva claramente o que mudou e por quê.

## Reportar bugs

Use o template de issue "Bug report" e inclua:
- Distribuição e versão do kernel (`uname -r`)
- Saída de `./scripts/diagnostico.sh`
- Logs relevantes (`dmesg | grep aic8800`)

## Código de conduta

Seja respeitoso e construtivo. Discriminação ou assédio não serão tolerados.
